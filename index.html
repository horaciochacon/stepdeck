Quick start

You need Node 20 or later and Chrome. Clone the repository, then:

git clone https://github.com/horaciochacon/stepdeck.git
cd stepdeck
npm install
node cli/index.js new ../my-talk       # a working three-slide deck, engine copied into my-talk/stepdeck/
node cli/index.js serve ../my-talk     # prints a URL; open it in Chrome

The arrow keys or space step through, S opens the presenter view. The full walk-through is in the quick start guide.
